---
title: "Share Previews & Embeds"
description: "Control how your short links look when shared on social media and chat apps."
icon: "share-nodes"
---

When your short links are shared on social media or messaging apps, SunLinks controls how the preview card looks. In the link details dialog, switch to the **Embed** tab:

| Field | Description |
| --- | --- |
| OG Title | The title shown in the preview card |
| OG Description | The description shown below the title |
| OG Image URL | A custom preview image. If blank, the automatically generated thumbnail is used. |

Click **Save Embed Settings** to apply. These settings control the OpenGraph meta tags served when bots (such as Twitter, Facebook or Discord) fetch your short URL.
