## Account details

Go to **Settings → Details** to manage your account:

* **Change Username**: update your display name.
* **Change Email**: update your email address.
* **Change Password**: enter and confirm a new password.

## Theme & branding

Admins can customize SunLinks under **Settings → Theme**:

* **Light / Dark Mode**
* **Site Name**: the branding name displayed in the app.
* **Color Customization**: Primary, Accent and Background colors; Body Text, Primary Text and Secondary Text colors; Error and Success status colors.
* **Reset to Defaults**: restore all branding and color settings.

## Access control

As a Global Admin, go to **Settings → Access Control** to toggle whether new accounts can be created. When account creation is turned off:

* The registration page cannot register new users
* The **Add New User** button on the User Management page is disabled
* Accounts are no longer created automatically for unregistered Discord members, so they cannot run slash commands
